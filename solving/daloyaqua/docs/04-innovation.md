# Innovation Log

Innovation is one of Cowboy's core assets. This log keeps it **disciplined**. Every idea is captured, tested in a small experiment, and kept or dropped based on evidence. It is never built just because it sounds exciting.

## Flow
```
idea ──► experiment ──► spec (specs/NNN)   ← evidence says yes
              └──────► parked               ← evidence says no / not now
```
- **idea:** written down with the problem it targets. Costs nothing.
- **experiment:** the *smallest* test (a conversation, a paper prototype, a 1-week manual trial). It has a success signal defined *before* it starts.
- **spec:** only when the experiment shows real pull. Then it follows `docs/03-sdlc.md`.
- **parked:** kept here with the reason. Parked ideas can come back when the evidence changes.

Habit: log 1 idea a week, run 1 tiny experiment a month (VGMO).
